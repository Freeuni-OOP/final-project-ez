# AlgoRythm

AlgoRythm არის ბრაუზერში მომუშავე აპლიკაცია, სადაც მუსიკას მარტივი ტექსტით წერ. წერ პატერნებს ტექსტად, აჭერ play-ს და ისმენ, როგორ ჟღერს. ეს ჩვენი OOP-ის ფინალური პროექტია.

## რას აკეთებს

მომხმარებელს შეუძლია:

* შექმნას და შეინახოს საკუთარი კომპოზიციები
* გამოაქვეყნოს კომპოზიცია და გააზიაროს ლინკით
* explore გვერდზე ნახოს სხვისი გამოქვეყნებული ნამუშევრები, მოძებნოს ისინი და გაფილტროს tag-ებით
* მოიწონოს კომპოზიცია და დაწეროს კომენტარი
* გამოიწეროს სხვა ავტორები და feed-ში ნახოს მათი ახალი ნამუშევრები
* მართოს საკუთარი ანგარიში, ანუ შეიცვალოს პაროლი და ელფოსტა, ან წაშალოს ანგარიში

## რითი არის დაწერილი

* Frontend: TanStack Start (React 19), TypeScript, Tailwind
* Backend: Spring Boot, Java 21
* ბაზა: PostgreSQL, სქემას Flyway მართავს
* ავტორიზაცია: JWT
* ყველაფერი ერთად იშვება Docker-ით

## როგორ გავუშვათ ლოკალურად

დაგჭირდება მხოლოდ Docker (მაგალითად Docker Desktop). ცალკე Java-ს, Node-ს ან ბაზას დაყენება საჭირო არ არის, ისინი კონტეინერებში ეშვება.

პროექტის საქაღალდიდან გაუშვი:

```
docker compose up --build
```

პირველი გაშვება ცოტა ხანს გრძელდება, სანამ იმიჯები აიწყობა. ამის მერე უფრო სწრაფად ჩაირთვება.

მას შემდეგ რაც ჩაირთვება, ბრაუზერში გახსენი:

* აპლიკაცია: http://localhost:3000
* backend API: http://localhost:8080

გასაჩერებლად ტერმინალში დააჭირე Ctrl+C, ან სხვა ტერმინალიდან გაუშვი `docker compose down`.

## როგორ იწერება პატერნი

თითოეული ხაზი ერთი ტრეკია. ხაზი ორწერტილით იყოფა: მარცხნივ ინსტრუმენტის სახელია, მარჯვნივ კი ნაბიჯები. ერთი ტოკენი ერთი ნაბიჯია, ხოლო `-` ნიშნავს პაუზას, ანუ სიჩუმეს.

მაგალითად:

```
drum: kick - kick - kick - kick -
drum: - hat - hat - hat - hat
bass: C2 - C2 - G1 - G1 -
```

დრამის ტოკენები (kick, hat, clap და სხვა) პერკუსიად იკვრება, ნოტები კი (მაგალითად C4 ან F#5) სიხშირედ გადაითვლება და მელოდიად ჟღერს. მეტი დეტალი აპლიკაციაში Syntax Guide-ის გვერდზეა.

## პროექტის სტრუქტურა

* `src/` არის frontend. გვერდები `src/routes/`-შია, API-ის გამოძახებები კი `src/lib/api.ts`-ში.
* `backend/` არის Spring Boot აპლიკაცია, დაყოფილი controller, service, repository და model ფენებად.
* `docker-compose.yml` ერთი ბრძანებით აწყობს frontend-ს, backend-ს და ბაზას.

## შენიშვნა

ლოკალურად ყველა პარამეტრს default მნიშვნელობა აქვს, ამიტომ დამატებით არაფრის მითითება არ არის საჭირო. რეალურ გარემოში JWT-ის საიდუმლო გასაღები `APP_JWT_SECRET`-ით უნდა გადაიწეროს.
